# Music (Batch E)

Drop tracks here; the game picks them up by name, trying .ogg, then .mp3,
then .wav:

    stage1   The Sunken Path
    stage2   Jungle Falls
    stage3   Ember Canyon
    boss     plays once you enter any boss arena (optional)

A stage without a file plays ../background_music.wav, so the game works
with this folder empty.  Use only tracks you may ship - CC0 (public domain)
needs no credit, CC-BY needs a credit line in the game or README.
